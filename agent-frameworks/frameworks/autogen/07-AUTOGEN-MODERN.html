AutoGen

Multi-agent systems where agents converse and collaborate

What is AutoGen?

AutoGen enables multiple AI agents to have conversations and collaborate on solving problems. Agents can be LLM-based or human-based, and they exchange messages until a solution is reached.

Key Features

✓ AssistantAgent (LLM-powered)
✓ UserProxyAgent (human in the loop)
✓ Conversation-based collaboration
✓ Tool use and code execution
✓ Flexible agent configuration
✓ Built-in failure recovery

Architecture: Two Agents Talking

In AutoGen, agents communicate through messages:

  • LoanAnalyst: Evaluates credit score and income
  • LoanReviewer: Reviews analyst's assessment and makes final decision

Complete Example

04_autogen_loan_evaluator.py
from autogen import AssistantAgent, UserProxyAgent, config_list_from_json
import json

# Configure model
config_list = [
    {
        "model": "claude-3-5-sonnet-20241022",
        "api_key": "sk-ant-your-key"
    }
]

# Create LoanAnalyst agent
analyst = AssistantAgent(
    name="LoanAnalyst",
    system_message="""You are a loan analyst. Your job is to:
1. Review credit score, income, and loan amount
2. Calculate debt-to-income ratio
3. Score the applicant (0-100)
4. Provide analysis to the reviewer

Scoring:
- Credit 750+: 40 points
- Credit 650-749: 25 points
- DTI <0.36: 40 points
- DTI 0.36-0.43: 25 points
- Loan <50% income: 20 points""",
    llm_config={
        "config_list": config_list,
        "temperature": 0.3
    }
)

# Create LoanReviewer agent
reviewer = AssistantAgent(
    name="LoanReviewer",
    system_message="""You are a senior loan reviewer. Your job is to:
1. Read the analyst's assessment
2. Make final decision: APPROVED, REVIEW, or DENIED
3. Provide reasoning

Decision rules:
- Score 80+: APPROVED
- Score 50-79: REVIEW
- Score <50: DENIED""",
    llm_config={
        "config_list": config_list,
        "temperature": 0.3
    }
)

# Create UserProxyAgent to facilitate
user_proxy = UserProxyAgent(
    name="Evaluator",
    human_input_mode="NEVER",
    max_consecutive_auto_reply=2,
    code_execution_config={"use_docker": False}
)

# Test applications
test_applications = [
    {
        "name": "Strong Candidate",
        "credit_score": 780,
        "annual_income": 150000,
        "loan_amount": 50000
    },
    {
        "name": "Borderline Case",
        "credit_score": 680,
        "annual_income": 65000,
        "loan_amount": 40000
    },
    {
        "name": "Risky Applicant",
        "credit_score": 580,
        "annual_income": 30000,
        "loan_amount": 50000
    }
]

if __name__ == "__main__":
    for app in test_applications:
        print(f"\n{'='*60}")
        print(f"Evaluating: {app['name']}")
        print(f"{'='*60}\n")
        
        dti = app["loan_amount"] / app["annual_income"]
        
        message = f"""Please evaluate this loan application:
        
Credit Score: {app['credit_score']}
Annual Income: ${app['annual_income']:,}
Loan Amount: ${app['loan_amount']:,}
DTI Ratio: {dti:.2f}

Analyst, provide your assessment. Reviewer, then make the final decision."""

        # Initiate conversation between agents
        user_proxy.initiate_chat(
            analyst,
            message=message
        )

How AutoGen Works

1. UserProxy sends message to Analyst
2. Analyst analyzes and sends response
3. Reviewer evaluates analyst's assessment
4. Agents continue talking until consensus
5. Final decision emerges from conversation

Key Concepts

1. AssistantAgent

An LLM-powered agent with a system message defining its role. Takes messages as input, generates responses.

2. UserProxyAgent

Represents the human or initiator. Can be fully automated (human_input_mode="NEVER") or require human approval.

3. Conversation Flow

Agents exchange messages until a termination condition is met (e.g., "APPROVED" detected, max turns reached).

4. Configuration

Set temperature, max replies, and code execution settings for each agent independently.

When to Use AutoGen

✓ Use for:

Complex problems requiring multiple perspectives, systems where agents should negotiate/discuss, scenarios with human-in-the-loop

✗ Skip if:

You have simple single-step tasks or need guaranteed decision consistency
