Building an Agent Loop from Scratch

Understanding how to build agents from first principles. This teaches the core ReAct pattern: Reason → Act → Observe → Repeat.

The ReAct Pattern (Reasoning + Acting)

1️⃣ Observe: Understand the current state
2️⃣ Reason: Think about what to do
3️⃣ Act: Call a tool or take action
4️⃣ Observe: See the result
5️⃣ Repeat: Continue until solved

Simple Agent Loop

import anthropic client = anthropic.Anthropic() tools = [ { "name": "check_credit_score", "description": "Check someone's credit score", "input_schema": { "type": "object", "properties": { "person": {"type": "string", "description": "Person's name"}, "score": {"type": "integer"} }, "required": ["person", "score"] } } ] # The Agent Loop def run_agent(user_message): messages = [{"role": "user", "content": user_message}] while True: # The Loop # Step 1: Get Claude's response response = client.messages.create( model="claude-3-5-sonnet-20241022", max_tokens=1024, tools=tools, messages=messages ) # Check if Claude wants to use a tool if response.stop_reason == "tool_use": # Step 2: Find which tool Claude wants to use for block in response.content: if block.type == "tool_use": tool_name = block.name tool_input = block.input tool_use_id = block.id # Step 3: Simulate tool result if tool_name == "check_credit_score": result = f"Credit score for {tool_input['person']}: {tool_input['score']}" # Step 4: Add tool result back to messages messages.append({"role": "assistant", "content": response.content}) messages.append({ "role": "user", "content": [ { "type": "tool_result", "tool_use_id": tool_use_id, "content": result } ] }) else: # Claude is done - return final answer final_response = "" for block in response.content: if hasattr(block, "text"): final_response += block.text return final_response # Run it result = run_agent("Evaluate John's loan (credit: 750)") print(result)

When to Build Custom Loops

✓ Build Custom When:

Learning how agents work, need maximum control, implementing custom logic, educational purposes

✗ Skip Custom When:

Need production speed, want maintained code, building complex workflows, team collaboration needed
