Strands Agents

AWS Model-Driven Framework for Autonomous AI Agents

What is Strands Agents?

Strands Agents is an open-source AWS framework that uses a model-driven approach. Instead of hardcoding workflows, you define 3 things: a model, a prompt, and tools. The LLM figures out how to use them autonomously.

Core Philosophy: Model-First

✓ Let the LLM reason autonomously
✓ Minimize boilerplate code
✓ Framework handles coordination
✓ Production-ready with observability
✓ Native AWS integration
✓ Native MCP support

Complete Example

06_strands_loan_evaluator.py
from strands import Agent, Tool
import anthropic
import json

# Define tools
@Tool
def calculate_dti(annual_income: float, loan_amount: float) -> float:
    """Calculate debt-to-income ratio"""
    return round(loan_amount / annual_income, 2)

@Tool
def check_credit_history(credit_score: int) -> dict:
    """Check if credit score meets thresholds"""
    return {
        "score": credit_score,
        "category": "excellent" if credit_score >= 750 else 
                   "good" if credit_score >= 650 else
                   "fair" if credit_score >= 600 else
                   "poor",
        "risky": credit_score < 600
    }

# Create agent with model-first approach
agent = Agent(
    model="claude-3-5-sonnet-20241022",  # LLM to use
    tools=[calculate_dti, check_credit_history],  # Tools it can call
    instructions="""You are a loan evaluation expert.
    
When given an application:
1. Use check_credit_history to assess credit
2. Use calculate_dti to get debt-to-income ratio
3. Make a decision: APPROVED, REVIEW, or DENIED
4. Score 0-100 based on creditworthiness

Return JSON with: decision, score, reasoning"""
)

# Test applications
test_apps = [
    {"credit_score": 780, "annual_income": 150000, "loan_amount": 50000},
    {"credit_score": 680, "annual_income": 65000, "loan_amount": 40000},
    {"credit_score": 580, "annual_income": 30000, "loan_amount": 50000}
]

if __name__ == "__main__":
    for app in test_apps:
        print(f"\n{'='*50}")
        print(f"Evaluating loan application")
        print(f"{'-'*50}")
        
        prompt = f"""Evaluate this loan application:
        Credit Score: {app['credit_score']}
        Annual Income: ${app['annual_income']:,}
        Loan Amount: ${app['loan_amount']:,}"""
        
        # Agent autonomously figures out what to do
        result = agent.run(prompt)
        print(result)

When to Use Strands

✓ Use Strands When:

Building production AWS systems, need autonomous reasoning, want minimal boilerplate, leveraging MCP tools, enterprise observability required

✗ Skip Strands When:

Need explicit deterministic workflows, want maximum control, building simple tasks, not using AWS

Why Strands is Special

  • Model-first: Let Claude reason, don't hardcode logic
  • Minimal setup: 3 components, agent handles rest
  • Production-ready: Observability, tracing, logging built-in
  • AWS native: Bedrock, Lambda, integrations ready
  • MCP native: Use any MCP server as a tool
  • Used by AWS: Amazon Q, AWS Glue, Kiro use it internally

Advanced: Multi-Step Autonomous Workflow

Strands excels at letting agents autonomously decide their path:

Multi-Tool Autonomous Example
# Define multiple tools
@Tool
def get_employment_verification(email: str) -> dict:
    """Get employment verification"""
    return {"verified": True, "employer": "Acme Corp"}

@Tool
def check_bankruptcy(ssn: str) -> dict:
    """Check bankruptcy history"""
    return {"has_bankruptcy": False, "years_ago": None}

@Tool
def calculate_affordability(income: float, debt: float) -> dict:
    """Calculate affordability score"""
    return {"affordable": debt/income < 0.43, "ratio": debt/income}

# Agent autonomously chooses which tools to use
agent = Agent(
    model="claude-3-5-sonnet-20241022",
    tools=[
        get_employment_verification,
        check_bankruptcy,
        calculate_affordability
    ],
    instructions="Make holistic loan decision considering all factors"
)

# Agent will call tools in order that makes sense
result = agent.run("Evaluate John Doe's loan application...")
