LangGraph

State machines and explicit workflows for complex applications

What is LangGraph?

LangGraph adds state management and explicit node graphs on top of LangChain. Perfect for applications with decision points, multiple steps, and complex routing.

Key Features

✓ StateGraph with TypedDict for type safety
✓ Explicit nodes (functions) and edges (routing)
✓ Conditional edges for branching logic
✓ Persistent state across steps
✓ Visual debugging
✓ Perfect for production workflows

Complete Example

03_langgraph_loan_evaluator.py
from langgraph.graph import StateGraph
from langchain.chat_models import ChatAnthropic
from typing_extensions import TypedDict
import json

# Define state schema
class LoanApplicationState(TypedDict):
    credit_score: int
    annual_income: float
    loan_amount: float
    dti_ratio: float
    evaluation: dict
    decision: str

# Initialize model
model = ChatAnthropic(model="claude-3-5-sonnet-20241022")

# Node 1: Gather information
def gather_info(state: LoanApplicationState) -> LoanApplicationState:
    """Calculate DTI and prepare for evaluation"""
    state["dti_ratio"] = state["loan_amount"] / state["annual_income"]
    print(f"✓ Info gathered - DTI: {state['dti_ratio']:.2f}")
    return state

# Node 2: Evaluate application
def evaluate_application(state: LoanApplicationState) -> LoanApplicationState:
    """Call Claude to evaluate"""
    prompt = f"""Evaluate this loan application:
    
Credit Score: {state['credit_score']}
Annual Income: ${state['annual_income']:,}
Loan Amount: ${state['loan_amount']:,}
DTI Ratio: {state['dti_ratio']:.2f}

Score and decide: APPROVED, REVIEW, or DENIED

Return ONLY valid JSON with: decision, score, reasoning"""

    response = model.invoke(prompt)
    state["evaluation"] = json.loads(response.content)
    print(f"✓ Evaluated - Score: {state['evaluation'].get('score')}")
    return state

# Node 3: Route decision
def route_decision(state: LoanApplicationState) -> str:
    """Route based on decision"""
    decision = state["evaluation"]["decision"]
    state["decision"] = decision
    return decision

# Node 4: Approve path
def approve_applicant(state: LoanApplicationState) -> LoanApplicationState:
    """Handle approved applications"""
    print("✓ Applicant APPROVED - Preparing offer")
    return state

# Node 5: Review path
def review_applicant(state: LoanApplicationState) -> LoanApplicationState:
    """Handle review cases"""
    print("✓ Application moved to REVIEW - Escalating")
    return state

# Node 6: Deny path
def deny_applicant(state: LoanApplicationState) -> LoanApplicationState:
    """Handle denied applications"""
    print("✓ Application DENIED - Sending notification")
    return state

# Build the graph
graph_builder = StateGraph(LoanApplicationState)

# Add nodes
graph_builder.add_node("gather_info", gather_info)
graph_builder.add_node("evaluate", evaluate_application)
graph_builder.add_node("approve", approve_applicant)
graph_builder.add_node("review", review_applicant)
graph_builder.add_node("deny", deny_applicant)

# Add edges
graph_builder.add_edge("START", "gather_info")
graph_builder.add_edge("gather_info", "evaluate")

# Conditional edge from evaluate
def should_approve(state):
    decision = state["evaluation"]["decision"]
    if decision == "approved":
        return "approve"
    elif decision == "review":
        return "review"
    else:
        return "deny"

graph_builder.add_conditional_edges("evaluate", should_approve)

# End paths
graph_builder.add_edge("approve", "END")
graph_builder.add_edge("review", "END")
graph_builder.add_edge("deny", "END")

# Compile graph
graph = graph_builder.compile()

# Test applications
test_applications = [
    {
        "credit_score": 780,
        "annual_income": 150000,
        "loan_amount": 50000
    },
    {
        "credit_score": 680,
        "annual_income": 65000,
        "loan_amount": 40000
    },
    {
        "credit_score": 580,
        "annual_income": 30000,
        "loan_amount": 50000
    }
]

# Run evaluations
if __name__ == "__main__":
    for i, app in enumerate(test_applications, 1):
        print(f"\n{'='*50}")
        print(f"Application {i}")
        print(f"{'-'*50}")
        
        # Create initial state
        initial_state = {
            "credit_score": app["credit_score"],
            "annual_income": app["annual_income"],
            "loan_amount": app["loan_amount"],
            "dti_ratio": 0,
            "evaluation": {},
            "decision": ""
        }
        
        # Execute workflow
        result = graph.invoke(initial_state)
        
        print(f"\n✓ FINAL DECISION: {result['decision']}")
        print(json.dumps(result['evaluation'], indent=2))

Key Concepts

1. StateGraph & TypedDict

TypedDict defines what data flows through the graph. Type-safe and self-documenting.

2. Nodes

Functions that take state in, do work, return updated state. Each node is a step in the workflow.

3. Edges

add_edge(from, to) connects nodes sequentially. add_conditional_edges(from, route_fn) for branching.

4. Conditional Routing

The route_decision function receives state and returns which node to go to next. Perfect for if/else logic.

5. Compile & Invoke

graph.compile() creates the executable workflow. graph.invoke(initial_state) runs it.

Why LangGraph?

Problem Solution
Complex workflows with many steps Explicit nodes + edges
Decision logic (if/else) Conditional edges
State management across steps TypedDict state schema
Hard to debug flow Visual workflow diagram
Testing individual steps Each node is testable function

When to Use LangGraph

✓ Use for:

Complex multi-step workflows, explicit branching logic, state management, production systems that need reliability and observability

✗ Skip if:

You have simple single-step tasks. LangChain might be simpler.
