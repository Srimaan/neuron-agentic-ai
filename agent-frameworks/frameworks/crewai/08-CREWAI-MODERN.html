CrewAI

Role-based AI agents working as a team to complete tasks

What is CrewAI?

CrewAI provides a higher-level abstraction for building teams of AI agents. Each agent has a role, goal, and backstory. Agents work together sequentially or in parallel to complete tasks.

Key Advantages

✓ Role-based agents (easier to reason about)
✓ Clear task definitions
✓ Sequential task execution
✓ Simpler than AutoGen
✓ Production-ready architecture
✓ Great for hierarchical teams

Team Structure

Our loan evaluation team:

  • LoanAnalyst: Analyzes applicant data
  • RiskAssessor: Evaluates risk
  • LoanManager: Makes final decision

Complete Example

05_crewai_loan_evaluator.py
from crewai import Agent, Task, Crew
from langchain.llms import Anthropic
import json

# Initialize LLM
llm = Anthropic(model="claude-3-5-sonnet-20241022")

# Define agents
analyst = Agent(
    role="Loan Analyst",
    goal="Analyze loan applications thoroughly",
    backstory="""You are an experienced loan analyst with 10 years
    of experience. You evaluate credit scores, income, and DTI ratios
    with precision and fairness.""",
    llm=llm,
    verbose=True
)

risk_assessor = Agent(
    role="Risk Assessor",
    goal="Assess risk level of loan applications",
    backstory="""You are a risk assessment expert. You evaluate
    probability of default and identify red flags.""",
    llm=llm,
    verbose=True
)

loan_manager = Agent(
    role="Loan Manager",
    goal="Make final lending decisions",
    backstory="""You are a senior loan manager who makes the final
    approve/deny decision based on analysis and risk assessment.""",
    llm=llm,
    verbose=True
)

# Define tasks
analysis_task = Task(
    description="""Analyze this loan application:
    Credit Score: {credit_score}
    Annual Income: ${annual_income}
    Loan Amount: ${loan_amount}
    DTI Ratio: {dti_ratio}
    
    Provide detailed analysis of creditworthiness.""",
    agent=analyst,
    expected_output="Detailed analysis of the applicant"
)

risk_task = Task(
    description="""Based on the analyst's report, assess the risk.
    Consider: credit score trend, income stability, DTI ratio.
    What is the probability of default?""",
    agent=risk_assessor,
    expected_output="Risk assessment with probability of default"
)

decision_task = Task(
    description="""Based on analysis and risk assessment, make a final
    decision: APPROVED, DENIED, or REVIEW.
    Explain your reasoning.""",
    agent=loan_manager,
    expected_output="Final decision with clear reasoning"
)

# Create crew (team)
crew = Crew(
    agents=[analyst, risk_assessor, loan_manager],
    tasks=[analysis_task, risk_task, decision_task],
    verbose=True
)

# Test applications
test_applications = [
    {
        "name": "Strong Candidate",
        "credit_score": 780,
        "annual_income": 150000,
        "loan_amount": 50000
    },
    {
        "name": "Borderline Case",
        "credit_score": 680,
        "annual_income": 65000,
        "loan_amount": 40000
    },
    {
        "name": "Risky Applicant",
        "credit_score": 580,
        "annual_income": 30000,
        "loan_amount": 50000
    }
]

if __name__ == "__main__":
    for app in test_applications:
        print(f"\n{'='*60}")
        print(f"Evaluating: {app['name']}")
        print(f"{'='*60}\n")
        
        dti = app["loan_amount"] / app["annual_income"]
        
        # Execute crew workflow
        result = crew.kickoff(
            inputs={
                "credit_score": app["credit_score"],
                "annual_income": app["annual_income"],
                "loan_amount": app["loan_amount"],
                "dti_ratio": f"{dti:.2f}"
            }
        )

Output

Final Result: APPROVED with strong recommendation

Key Concepts

1. Agent

Defined by role, goal, and backstory. Each agent is focused on their specialty.

2. Task

A specific job an agent performs. Tasks define expected output format and success criteria.

3. Crew

Manages the team of agents and their tasks. Coordinates execution and passes results between tasks.

4. Sequential Execution

By default, tasks run in order. Task 1's output feeds into Task 2, etc. Results propagate through the team.

All 5 Frameworks Compared

Framework Abstraction Best For Difficulty
Raw SDK None (direct API) Learning fundamentals Easy
LangChain Components & chains Rapid development Moderate
LangGraph State machines Complex workflows Advanced
AutoGen Agent conversations Multi-agent debate Advanced
CrewAI Role-based teams Hierarchical teams Moderate

Choosing the Right Framework

Use Raw SDK when:

Learning how APIs work, building simple one-off tasks

Use LangChain when:

Building reusable components, moderate complexity applications

Use LangGraph when:

Complex workflows with branching logic and state management

Use AutoGen when:

Agents need to debate and reach consensus on decisions

Use CrewAI when:

Building role-based teams where agents have clear jobs and work sequentially
