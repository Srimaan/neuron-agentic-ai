What is Haystack?

Haystack is a Python framework optimized for RAG (Retrieval-Augmented Generation) and agentic pipelines. Built by deepset, it excels at document retrieval, processing, and agent-driven workflows.

Key Strengths

Pipeline-Based Approach

08_haystack_rag_agent.py
from haystack import Pipeline, Document
from haystack.components.retrievers.in_memory import InMemoryBM25Retriever
from haystack.components.builders import PromptBuilder
from haystack.components.generators import OpenAIGenerator
from haystack.document_stores.in_memory import InMemoryDocumentStore

# Create document store
doc_store = InMemoryDocumentStore()

# Add example documents (loan policies)
docs = [
    Document(content="DTI ratio must not exceed 43%"),
    Document(content="Credit score minimum: 600"),
    Document(content="Income verification required")
]
doc_store.write_documents(docs)

# Build RAG pipeline
pipeline = Pipeline()
pipeline.add_component("retriever", 
    InMemoryBM25Retriever(doc_store))
pipeline.add_component("prompt_builder", 
    PromptBuilder(template="Based on: {{documents}}\nQuestion: {{query}}\nAnswer:"))
pipeline.add_component("llm", 
    OpenAIGenerator(model="claude-3-5-sonnet-20241022"))

# Connect components
pipeline.connect("retriever.documents", "prompt_builder.documents")
pipeline.connect("prompt_builder.prompt", "llm.prompt")

# Run pipeline
result = pipeline.run({
    "retriever": {"query": "What is maximum DTI ratio?"},
    "prompt_builder": {"query": "What is maximum DTI ratio?"}
})

print(result)
