Semantic Kernel

Microsoft's Plugin-Based Framework for Enterprise AI

What is Semantic Kernel?

Microsoft's Semantic Kernel provides a plugin architecture for building AI applications. Plugins are reusable components that encapsulate LLM calls and tools, making them highly composable and shareable.

Key Strengths

✓ Enterprise .NET + Python support
✓ Plugin-based architecture (reusable components)
✓ Memory management built-in
✓ Azure integration
✓ Large ecosystem
✓ Great for corporate environments

Plugin-Based Architecture

Semantic Kernel organizes functionality into plugins—reusable, composable units:

07_semantic_kernel_loan_evaluator.py
from semantic_kernel import Kernel
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion
import semantic_kernel.core_plugins as core_plugins

# Initialize kernel
kernel = Kernel()
kernel.add_chat_service(
    "claude",
    OpenAIChatCompletion(
        model_id="claude-3-5-sonnet-20241022",
        api_key="sk-ant-..."
    )
)

# Create plugins (reusable functions)
class CreditPlugin:
    @kernel.function_name("check_credit")
    def check_credit_score(self, score: int) -> str:
        """Evaluate credit score"""
        if score >= 750:
            return "Excellent (40 points)"
        elif score >= 650:
            return "Good (25 points)"
        else:
            return "Poor (0 points)"

class LoanPlugin:
    @kernel.function_name("evaluate_loan")
    def evaluate(self, credit: str, income: float, 
                 loan: float) -> str:
        """Main evaluation logic"""
        dti = loan / income
        return f"Credit: {credit}, DTI: {dti:.2f}"

# Register plugins
kernel.register_plugin(CreditPlugin(), "credit")
kernel.register_plugin(LoanPlugin(), "loan")

# Use plugins
prompt = """Evaluate this loan:
Credit Score: {credit_score}
Income: ${income}
Loan: ${loan_amount}

Use the credit and loan plugins to assess."""

result = kernel.invoke(
    prompt,
    credit_score=780,
    income=150000,
    loan_amount=50000
)

print(result)
