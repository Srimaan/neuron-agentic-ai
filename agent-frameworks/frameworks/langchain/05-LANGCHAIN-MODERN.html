LangChain

Reusable components for building LLM applications

What is LangChain?

LangChain provides abstractions like ChatPromptTemplate, OutputParser, and Chain that simplify building LLM applications.

Key Advantages

✓ Reusable components (templates, parsers)
✓ Cleaner syntax than raw SDK
✓ Built-in support for different output formats
✓ Easy to compose chains of operations
✓ Better for production code

Complete Example

02_langchain_loan_evaluator.py
from langchain.chat_models import ChatAnthropic
from langchain.prompts import ChatPromptTemplate
from langchain.output_parsers import JsonOutputParser
from langchain.schema import HumanMessage
import json

# Initialize the model
model = ChatAnthropic(model="claude-3-5-sonnet-20241022")

# Create prompt template
prompt = ChatPromptTemplate.from_messages([
    (
        "system",
        """You are a loan evaluation system.

CRITERIA SCORING:
- Credit Score 750+: 40 points
- Credit Score 650-749: 25 points
- Credit Score 600-649: 10 points
- Credit Score <600: 0 points

- Debt-to-Income Ratio <0.36: 40 points
- Debt-to-Income Ratio 0.36-0.43: 25 points
- Debt-to-Income Ratio >0.43: 0 points

- Loan Amount <50% of income: 20 points
- Loan Amount 50-100% of income: 10 points
- Loan Amount >100% of income: 0 points

DECISION RULES:
- Score 80+: APPROVED
- Score 50-79: REVIEW
- Score <50: DENIED

Output ONLY valid JSON."""
    ),
    (
        "user",
        """Evaluate this application:
Credit Score: {credit_score}
Annual Income: ${annual_income}
Loan Amount: ${loan_amount}
DTI Ratio: {dti_ratio:.2f}

Return JSON with: decision, score, reasoning"""
    )
])

# Create parser
parser = JsonOutputParser()

# Create the chain
chain = prompt | model | parser

# Test applications
test_applications = [
    {
        "name": "Strong Candidate",
        "credit_score": 780,
        "annual_income": 150000,
        "loan_amount": 50000
    },
    {
        "name": "Borderline Case",
        "credit_score": 680,
        "annual_income": 65000,
        "loan_amount": 40000
    },
    {
        "name": "Risky Applicant",
        "credit_score": 580,
        "annual_income": 30000,
        "loan_amount": 50000
    }
]

# Run evaluations
if __name__ == "__main__":
    for app in test_applications:
        # Calculate DTI ratio
        dti = app["loan_amount"] / app["annual_income"]
        
        print(f"\n{'='*50}")
        print(f"Evaluating: {app['name']}")
        print(f"{'-'*50}")
        
        # Invoke chain with data
        result = chain.invoke({
            "credit_score": app["credit_score"],
            "annual_income": app["annual_income"],
            "loan_amount": app["loan_amount"],
            "dti_ratio": dti
        })
        
        print(json.dumps(result, indent=2))

Output

Same as Raw SDK, but cleaner code!

{

Key Concepts

1. ChatPromptTemplate

Template for building prompts with placeholders. Notice the {variable_name} syntax — these get replaced when you invoke the chain.

2. Pipe Operator (|)

In LangChain, | chains operations: prompt | model | parser means "create prompt → send to model → parse output"

3. JsonOutputParser

Automatically converts Claude's JSON string response into a Python dict. No need for manual json.loads()!

4. Invoke

chain.invoke() runs the chain with your data. Returns the final parsed output.

Compared: Raw SDK vs LangChain

Aspect Raw SDK LangChain
Lines of Code ~80 ~50
Output Parsing Manual json.loads() JsonOutputParser
Prompt Management String variable ChatPromptTemplate
Composition Manual chaining Pipe operator (|)
Reusability Low High
Learning Curve Moderate Easy

Advanced: Memory & Conversation

LangChain makes it easy to add memory for multi-turn conversations:

With Conversation Memory
from langchain.memory import ConversationBufferMemory

# Add memory
memory = ConversationBufferMemory(return_messages=True)

# Chain remembers context across turns
for user_message in ["First question", "Follow-up question"]:
    result = chain.invoke({
        "input": user_message,
        "chat_history": memory.buffer
    })
    memory.save_context(
        {"input": user_message},
        {"output": result}
    )

When to Use LangChain

✓ Use LangChain When:

You need to build production applications with reusable components, templates, and parsers. Great for teams working on similar LLM patterns.

✗ Don't Use When:

You need maximum control or have very simple one-off tasks. Raw SDK might be simpler.
