Git & GitHub

For cloning repositories

🚀 Setup Steps

1

Create Project Directory

Create a folder for your bootcamp work:

$ mkdir ai-bootcamp && cd ai-bootcamp
2

Create Virtual Environment

Python needs an isolated environment:

$ python -m venv venv $ source venv/bin/activate # On Windows: venv\Scripts\activate
3

Install Dependencies

Create requirements.txt:

anthropic==0.24.0 langchain==0.1.0 langgraph==0.0.1 pyautogen==0.2.0 crewai==0.1.0 pydantic==2.5.0 python-dotenv==1.0.0 pytest==7.4.0

Then install:

$ pip install -r requirements.txt
4

Configure API Key

Create .env file in project root:

ANTHROPIC_API_KEY=sk-ant-your-key-here

⚠️ Security Warning

Never commit .env to git. Add to .gitignore!

5

Download Course Materials

Copy all course files to your project directory. Should have:

├── 01-PROMPT-ENGINEERING-101.md ├── 01-PROMPT-ENGINEERING-EXERCISES.md ├── 01-PROMPT-ENGINEERING-example-01-raw-sdk.py ├── 01-PROMPT-ENGINEERING-example-02-langchain.py ├── 01-PROMPT-ENGINEERING-example-03-langgraph.py ├── 01-PROMPT-ENGINEERING-example-04-autogen.py ├── 01-PROMPT-ENGINEERING-example-05-crewai.py ├── requirements.txt └── .env
6

Verify Setup

Run the verification script:

$ python verify_setup.py

This checks:

  • Python version 3.11+
  • All packages installed
  • API key configured
  • Can connect to Claude API
7

Run First Example

Test with the Raw SDK example:

$ python 01-PROMPT-ENGINEERING-example-01-raw-sdk.py

✓ Success!

You should see JSON output with loan evaluation decisions.

8

Optional: Setup Docker

For databases (PostgreSQL, Redis):

$ docker-compose up -d

This requires docker-compose.yml in project root.

🔧 Troubleshooting

Issue Solution
"ModuleNotFoundError: anthropic" Run: pip install -r requirements.txt
"API key not found" Make sure .env file exists with ANTHROPIC_API_KEY
"Python version too old" Install Python 3.11 or later from python.org
"Permission denied" on venv/bin/activate On Windows, use: venv\Scripts\activate
"json.JSONDecodeError" Claude response isn't valid JSON. Check prompt format.
"Connection timeout" Check internet connection. API might be down.

✅ Verification Script

Save this as verify_setup.py:

#!/usr/bin/env python3 import sys import os from pathlib import Path print("🔍 Verifying Setup...\n") # Check Python version print(f"✓ Python: {sys.version.split()[0]}", "✓" if sys.version_info >= (3, 11) else "✗") # Check packages packages = ['anthropic', 'langchain', 'pydantic'] for pkg in packages: try: __import__(pkg) print(f"✓ {pkg}") except ImportError: print(f"✗ {pkg} (run: pip install -r requirements.txt)") # Check .env file if Path('.env').exists(): print("✓ .env file found") else: print("✗ .env file missing") # Check API key if os.getenv('ANTHROPIC_API_KEY'): print("✓ ANTHROPIC_API_KEY set") else: print("✗ ANTHROPIC_API_KEY not set") print("\n✓ Setup verified!" if all else "✗ Fix issues above")

✓ Ready!

If all checks pass, you're ready to start learning!
