Week 1, Day 1: Setup & Code

Get your environment ready & explore all 5 frameworks

🚀 Setup in 8 Steps

1 Check Prerequisites

Make sure you have these installed:

🐍
Python 3.11+
Run: python3 --version
🐳
Docker Desktop
Run: docker --version
🔑
Claude API Key
Get from console.anthropic.com

2 Create Project Directory

mkdir ai-bootcamp-week1 cd ai-bootcamp-week1

3 Create Virtual Environment

python3 -m venv venv source venv/bin/activate # On Windows: venv\Scripts\activate

4 Install Packages

Create requirements.txt:

anthropic==0.29.0 langchain==0.1.0 langchain-anthropic==0.1.0 langgraph==0.0.40 pyautogen==0.2.0 crewai==0.1.0 python-dotenv==1.0.0
pip install -r requirements.txt

5 Configure API Key

Create .env:

ANTHROPIC_API_KEY=your_api_key_here

6 Verify Installation

python -c "import anthropic; print('✅ Anthropic SDK installed')"
✅
If you see "✅ Anthropic SDK installed" → You're ready!

7 Run First Example

python 01-PROMPT-ENGINEERING-example-01-raw-sdk.py
🎉
Should see loan decisions with JSON output

8 Explore All Examples

Try each framework:

# Framework 1: Raw SDK (fastest, most control) python 01-PROMPT-ENGINEERING-example-01-raw-sdk.py # Framework 2: LangChain (templates, abstractions) python 01-PROMPT-ENGINEERING-example-02-langchain.py # Framework 3: LangGraph (workflows, state machines) python 01-PROMPT-ENGINEERING-example-03-langgraph.py # Framework 4: AutoGen (multi-agent) python 01-PROMPT-ENGINEERING-example-04-autogen.py # Framework 5: CrewAI (role-based teams) python 01-PROMPT-ENGINEERING-example-05-crewai.py

💻 5 Frameworks, Same Task

Each example evaluates a loan application using the same prompt, but with different frameworks.

1️⃣ Raw Python SDK

Direct Claude API
✓ Maximum control
✓ No abstractions
✓ Fast execution
✓ Best for learning
Use when:

Simple scripts, learning, custom needs

2️⃣ LangChain

Abstractions & templates
✓ Prompt templates
✓ Chainable components
✓ Less boilerplate
✓ Production-ready
Use when:

Rapid prototyping, reusable chains, most projects

3️⃣ LangGraph

State machines
✓ Explicit workflows
✓ State management
✓ Easy debugging
✓ Agent-friendly
Use when:

Complex workflows, multi-step agents, production

4️⃣ AutoGen

Multi-agent orchestration
✓ Agent conversations
✓ Agent collaboration
✓ Built-in communication
✓ Complex reasoning
Use when:

Multiple specialists needed, agent debates

5️⃣ CrewAI

Role-based teams
✓ Role abstractions
✓ Task-driven
✓ Clean API
✓ Hierarchies
Use when:

Team simulations, clear hierarchies, rapid prototyping
