## 💡 KEY CONCEPTS FROM DAY 1

After completing all materials, you'll understand:

1. **What is Prompt Engineering?**
   - Writing clear instructions for Claude
   - Different from machine learning training
   - Can be tested and improved

2. **The 5 Principles**
   - Be specific (no vagueness)
   - Give context (explain the domain)
   - Show examples (good + bad)
   - Specify format (JSON, XML, etc)
   - Define constraints (thresholds, rules)

3. **Real Application**
   - Loan evaluation system
   - V1→V3 evolution (vague → specific → production)
   - Scoring system with thresholds
   - JSON output format

4. **Framework Agnostic**
   - Same prompt works in all frameworks
   - Only the delivery method changes
   - Python SDK, LangChain, LangGraph, AutoGen, CrewAI

5. **Testing Prompts**
   - Consistency across different inputs
   - Format validation (is JSON always valid?)
   - Decision quality (does it match business logic?)
