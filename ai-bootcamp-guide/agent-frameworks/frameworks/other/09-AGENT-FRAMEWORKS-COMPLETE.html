🌟 Strands Agents — NEW FRAMEWORK

Strands Agents is an AWS open-source framework emphasizing model-driven autonomy. Instead of hardcoding workflows, you give Claude your prompt + tools, and it figures out what to do automatically.

AWS Open Source
Strands Agents SDK
Production-ready framework for autonomous agents with native AWS integration

Key Features

  • Model-driven orchestration (LLM decides what to do)
  • Works with any LLM (Claude, Llama, etc.)
  • Built-in observability & logging
  • AWS integration (Bedrock, Lambda)
  • Production security & scalability
  • Multi-step autonomy
Best For: Systems that need autonomous reasoning, AWS environments, complex tool chains where the LLM should decide what to do

Strands Example: Loan Evaluation

strands_loan_evaluator.py
from strands_agents import Agent, Tool
from anthropic import Anthropic
import json

# Define tools (what the agent can do)
def check_credit_score(applicant_id: str) -> dict:
    """Get credit score from database"""
    return {"credit_score": 750, "history_years": 5}

def check_income(applicant_id: str) -> dict:
    """Verify income from tax records"""
    return {"annual_income": 150000, "employer": "TechCorp"}

def evaluate_debt(applicant_id: str) -> dict:
    """Calculate debt-to-income ratio"""
    return {"existing_debt": 30000, "dti_ratio": 0.20}

# Create tools
tools = [
    Tool(
        name="check_credit_score",
        description="Check applicant's credit score and history",
        func=check_credit_score
    ),
    Tool(
        name="check_income",
        description="Verify annual income",
        func=check_income
    ),
    Tool(
        name="evaluate_debt",
        description="Calculate debt-to-income ratio",
        func=evaluate_debt
    )
]

# Create agent
agent = Agent(
    name="LoanEvaluator",
    instructions="""You are a loan evaluation agent. 
    
Your job:
1. Use available tools to gather applicant information
2. Analyze credit score, income, and DTI ratio
3. Make decision: APPROVED, DENIED, or REVIEW
4. Explain your reasoning

Decision rules:
- Credit 750+: Strong approval candidate
- Credit 650-749: Likely approval with conditions
- DTI >0.43: Requires income verification
- Red flags: Recent bankruptcy, late payments

Be thorough. Use all available tools before deciding.""",
    
    model="claude-3-5-sonnet-20241022",
    tools=tools
)

# Test application
applicant_id = "APP-2024-001234"

# Run agent (it autonomously decides what to do)
result = agent.run(
    f"Evaluate loan application for {applicant_id}. "
    f"Requested loan amount: $50,000"
)

print("Agent Analysis:")
print(result.output)
print("\nTools Used:")
for tool_call in result.tool_calls:
    print(f"- {tool_call.name}")

Why Strands is Different

Model-Driven vs Workflow-Driven

Workflow-Driven (LangGraph): You define nodes and edges. Very explicit control.

Model-Driven (Strands): You give Claude the tools. It decides what to do. More autonomous.

✓ Advantages
  • Model handles complexity
  • Less code required
  • True autonomy
  • Works with any LLM
  • AWS-optimized
  • Production-ready
− Trade-offs
  • Less predictable
  • Harder to debug
  • API costs vary
  • Requires good prompts
  • Newer framework
  • AWS-biased

Hybrid Approaches (Combining Frameworks)

LangGraph + Strands Pattern

Use LangGraph for explicit workflows, but within each node use Strands agents for autonomous decisions:

graph.add_node("gather_data", strands_agent.run)
graph.add_node("analyze", langgraph_analyze_step)
graph.add_node("decide", strands_agent.run)

LangChain + LangGraph

Use LangChain for components, LangGraph for orchestration:

# Components from LangChain
prompt = ChatPromptTemplate.from_messages([...])
parser = JsonOutputParser()

# Orchestration from LangGraph
graph.add_node("evaluate", create_langchain_chain(prompt | model | parser))

CrewAI + LangGraph

CrewAI for simpler agent teams, LangGraph when you need state machines:

# Simple teams → CrewAI
crew = Crew(agents=[analyst, reviewer])

# Complex workflows → LangGraph nodes call crew tasks
graph.add_node("team_phase", crew.kickoff)
