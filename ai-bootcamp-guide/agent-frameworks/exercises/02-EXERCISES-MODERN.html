Write a Loan Evaluation Prompt
Easy
⏱️ 30 minutes
Goal: Write a prompt from scratch that evaluates loan applications.

Requirements:
  • Define the role (loan officer)
  • Specify the criteria (credit score, income, DTI)
  • Define the decision threshold
  • Specify JSON output format
Task:
  • Create a prompt that evaluates: credit score, annual income, desired loan amount
  • Output decision + score (0-100) + reasoning
  • Test it with a sample application
✓ Show Solution

Example Solution:

You are a loan evaluation system.

CRITERIA:
- Credit Score 750+: Excellent (40 points)
- Credit Score 650-749: Good (25 points)
- Credit Score 600-649: Fair (10 points)
- Credit Score <600: Poor (0 points)

- Debt-to-Income Ratio <0.36: Excellent (40 points)
- Debt-to-Income Ratio 0.36-0.43: Good (25 points)
- Debt-to-Income Ratio >0.43: Poor (0 points)

DECISION RULES:
- Score 80+: APPROVED
- Score 50-79: REVIEW
- Score <50: DENIED

INPUT: JSON with credit_score, annual_income, loan_amount
OUTPUT: JSON with decision, score, reasoning

Evaluate this application: 
{applicant data}

3
Test Prompt Consistency
Medium
⏱️ 40 minutes
Goal: Create a test harness to verify your prompt works consistently.

Write code that:
  • Tests 3 applications multiple times
  • Tracks if decisions are consistent
  • Reports any inconsistencies
Task:
  • Create 3 test cases (approve, deny, borderline)
  • Call Claude API 3 times for each
  • Check if results are consistent
  • Report consistency percentage
✓ Show Solution 
from anthropic import Anthropic
import json

client = Anthropic()

test_cases = [
    {"credit_score": 780, "income": 120000, "loan": 40000},
    {"credit_score": 580, "income": 30000, "loan": 50000},
    {"credit_score": 650, "income": 60000, "loan": 35000},
]

for test_num, app in enumerate(test_cases, 1):
    decisions = []
    for attempt in range(3):
        response = client.messages.create(
            model="claude-3-5-sonnet-20241022",
            max_tokens=200,
            messages=[{
                "role": "user",
                "content": f"Evaluate: {json.dumps(app)}"
            }]
        )
        result = json.loads(response.content[0].text)
        decisions.append(result["decision"])
    
    consistency = len(set(decisions)) == 1
    print(f"Test {test_num}: {'✓' if consistency else '✗'} {decisions}")

Adapt Prompt to Different Frameworks
Medium
⏱️ 45 minutes
Goal: Take your prompt and implement it in 2 different frameworks.

Choose 2 of: LangChain, LangGraph, AutoGen, CrewAI
Task:
  • Implement prompt in Framework 1
  • Implement prompt in Framework 2
  • Test both with same application
  • Compare results
✓ Show Solution (LangChain) 
from langchain.chat_models import ChatAnthropic
from langchain.prompts import ChatPromptTemplate
from langchain.output_parsers import JsonOutputParser

model = ChatAnthropic(model="claude-3-5-sonnet-20241022")
parser = JsonOutputParser()

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a loan evaluation system..."),
    ("user", "Evaluate this application: {application}")
])

chain = prompt | model | parser

result = chain.invoke({"application": json.dumps(app)})

Improve Based on Failures
Hard
⏱️ 60 minutes
Goal: Create production-grade prompt with edge cases handled.

Handle these edge cases:
  • Missing employment verification
  • Recent bankruptcies
  • High debt-to-income ratio but high income
  • Very young credit history (< 1 year)
Task:
  • Create comprehensive prompt with all edge cases
  • Test with 5 edge case applications
  • Verify decisions make business sense
  • Document your decision logic
✓ Show Solution 
EDGE CASES:
1. Missing Employment: AUTO-REVIEW (cannot approve without verification)
2. Recent Bankruptcy (<2 years): MAX 50 points regardless of other factors
3. DTI >0.50: AUTO-DENY unless approved by manager flag
4. Credit History <1 year: MAX 60 points (insufficient history)
5. Multiple Recent Inquiries (>3 in 6 months): -10 points per inquiry

These rules take precedence over standard scoring.
